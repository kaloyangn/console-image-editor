    Good to know · formats, privacy & limits
    • This edition runs in your browser. Images are not sent to a server by the app. On an HTTP website the page itself is delivered without encryption; use trusted hosting and avoid sensitive images there.
    • PNG, JPEG, WebP and GIF are decoded by your browser. Animated GIF/WebP use the browser's default/first frame only. Animated PNG is rejected to avoid confusing the default image with frame zero. TIFF, PSD, PDF, HEIC, AVIF and other desktop formats are not included.
    • SVG is rasterized with a minimum longest edge of 2048 pixels. Larger SVG dimensions are retained within the working limits. SVG with scripts, animations, embedded images, external references or style sheets is rejected. Text uses available fonts; complex filters may render differently. SVGZ requires the optional built-in gzip decoder.
    • Work limits: 40 files, 32 MiB each, 200 MiB total input, 16 million pixels and 8192 pixels per edge. Background padding must fit these limits. Results have a 100 MiB total budget. Limits protect browser memory, not guarantee performance.
    • Compression tries PNG re-encoding, then reduced RGB precision and smaller dimensions until the file is strictly below 5 MiB. Color and size may change. Later actions can increase the size again.
    • New files omit source EXIF, GPS and text metadata; the browser may add resolution or color information. Copyright-only retention is not available. Color profiles, HDR and print fidelity are not guaranteed.
    • The app uses distinct download names within this session. Your browser controls destination folders and collisions with existing files. A ZIP download is available to save a batch in one click.
    • Recipes contain only action settings. Export/import them to reuse settings elsewhere. Images and results are kept for this page session only; reload clears them. Stop finishes the current file before stopping.
