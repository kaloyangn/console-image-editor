    Browser differences, formats & limits
    • This is a browser mirror of the console workflow. It cannot run the Windows ImageMagick engine. Inputs: PNG, JPEG, WebP, GIF and a restricted static SVG subset. Outputs: PNG, JPEG, WebP (when supported) and ICO. GIF/WebP animation uses the default/first frame; APNG is rejected. No TIFF, PSD, HEIC, AVIF, PDF, layers or animation editing.
    • SVG renders at a minimum longest edge of 2048, preserving aspect and larger dimensions. Raster inputs are not enlarged automatically. Scripts, animations, embedded images, external references and style sheets in SVG are rejected. Fonts and filters may differ. SVGZ needs the browser’s built-in gzip decoder.
    • Backgrounds trim transparent edges only; opaque backgrounds stay intact. Padding is 0..4096 whole pixels per side. Compression produces PNG strictly below 5 MiB, with possible color/size loss. Put compression last in a chain.
    • Source metadata is not copied. The browser may add color or resolution information. Copyright-only retention is unavailable. Output [O] controls automatic/manual downloads, not filesystem folders. The browser controls existing-file collisions. Images and settings are not persisted after reload.
    • Limits: 40 files, 32 MiB each, 200 MiB total input; 8192 pixels per edge, 16 million pixels per canvas, 100 MiB total output; SVG up to 8 MiB/10,000 elements. Limits bound common memory use, not guarantee performance.
    • The app makes no upload, analytics or external dependency requests. HTTP delivery is unencrypted; use trusted hosting and avoid sensitive images there. Valid HTTPS and actual Vivacom deployment remain unverified.
    • Press a letter shortcut to activate immediately, or use ↑/↓ and Enter. Menus wrap. Home/End select first/last. In an action chain, Enter activates the highlighted row; after adding a step the Run row is selected. Backspace undoes the last step. Esc cancels a prompt/menu; during processing it stops after the current file. On the drop screen Esc pauses the session instead of closing a browser tab.
